## Part 1: 世界观设计

### WD1：世界观深度 — 中量级

种族有文化背景和基础地理，卡牌事件与世界观挂钩，但不需要完整历史线。

### WD2：叙事方式 — 固定叙事

每种族有固定的剧情线，玩家推进主线解锁新区域和新内容。同时存在支线目标供练级刷资源。

### WD3：出征结构 — 主线 + 支线

```
出征结构：
├── 主线远征 → 推进剧情，解锁新区域
└── 支线远征 → 刷资源、练级、获取道具/Buff
```

远征目标不受剧情限制，但只有打通主线才能继续剧情、解锁新区域。

### WD4：跨种族编队

玩家选择种族决定将军技能风格，但可以招募所有种族的士兵组成混合军队。

### WD5：种族关系 — 纯粹团结

各种族结成纯粹的同盟关系，不设计政治勾心斗角，渲染"世界民族大团结"的氛围，赞扬伟大的牺牲精神——不只是为自己的种族而牺牲，还有为拯救他人种族而牺牲的精神。

灵感来源：白求恩医生（跨国界奉献）、飞越喜马拉雅山的美军飞行员（为盟友冒死运输）。

### WD6：外部敌人 — 虚空（Void）

> 虚空是一个异界维度，正在侵蚀这个世界。虚空中的生物不直接战斗，而是**腐蚀（Corruption）**生灵，将被腐蚀的士兵变为没有自我意志的傀儡，为其作战。

**设计优势：**
- 所有种族都能作为敌人出现（被腐蚀版本）
- 敌方弹珠 = 同盟种族弹珠的暗色变体，视觉开发成本极低
- 击杀 = 解放同胞，暴力行为有正面道德框架
- 虚空生物本身作为Boss/精英怪，形态独特不规则

**虚空层次结构：**

| 层级 | 名称 | 表现 |
|------|------|------|
| 杂兵 | 腐化士兵 | 各种族弹珠的暗色变体，行为模式与原种族相同 |
| 精英 | 腐化军官 | 被腐蚀的高级兵种，数值更高，有腐蚀光环 |
| Boss | 虚空裂隙体 | 不规则形态异界生物，会释放腐蚀波、分裂、瞬移 |
| 终极 | 虚空主宰 | 最终Boss，整个侵蚀事件的源头 |

**核心主题对比：**
- 虚空：控制、腐蚀、抹杀自由意志、不理解牺牲
- 同盟：自由、团结、自愿牺牲、爱超越种族

### WD7：大陆与虚空裂隙

地图为纯叙事用途，不为玩家提供地图玩法交互，但展示一张完整大陆给玩家看。

虚空不是从某个方向侵蚀，而是在大陆各处打开**虚空裂隙**，腐化士兵从裂隙中涌出。每个裂隙是独立的副本点，远征目标就是前往裂隙附近执行任务。

**大陆区域（首发）：**

| 区域 | 对应种族 | 虚空裂隙 | 特征 | 卡牌事件主题 |
|------|----------|----------|------|-------------|
| 人类王国 | 人类 | 初始裂隙 | 平原、城堡、村庄 | 平民撤离、补给线、侦察 |
| 精灵密林 | 精灵 | 古树裂隙 | 森林、河流、遗迹 | 森林迷路、古代机关、精灵传统 |
| 兽人荒原 | 兽人 | 红岩裂隙 | 荒漠、峡谷、部落 | 沙暴、水源争夺、兽人试炼 |

### WD8：兵种获取 — 远征即解锁

远征任务本身也是获取新兵种的途径：

```
兵种解锁流程：
1. 主线推进到一定阶段 → 出现"援护远征"任务
2. 完成该远征 → 解锁该种族的基础兵种
3. 后续支线/主线可继续解锁该种族的高级兵种
```

示例（玩家选人类开局）：
- 主线第2章 → 援护远征：护送精灵使者 → 解锁月刃舞者+德鲁伊
- 支线远征 → 精灵密林深处探索 → 解锁游侠
- 主线第4章 → 精灵圣树保卫战 → 解锁树卫士

### WD9：种族在同盟中的角色与叙事线

| 种族 | 在同盟中的角色 | 典型叙事线 |
|------|--------------|-----------|
| 人类 | 发起者，最先遭受虚空侵蚀 | 人类将军跨越种族为精灵守卫防线 |
| 精灵 | 古老种族，自愿分享力量 | 精灵弓箭手放弃圣树去保护人类平民撤退 |
| 兽人 | 曾经被恐惧，此刻第一个站出来保护曾经的敌人 | 兽人战士用身体堵住虚空裂隙 |

## Part 2: 兵种体系设计

### UD1：物理维度 — 弹珠体型决定基础属性

```
小型弹珠：轻、快、脆、碰撞力小
中型弹珠：均衡
大型弹珠：重、慢、硬、碰撞力大（大球撞小球会直接把小球弹飞）
```

体型克制链：大球碾压小球，但大球容易被远程风筝；小球打不过大球但数量多可以围殴。

### UD2：13个兵种 — 3种族

#### 人类王国（5个 — 核心军团，兵种最全）

| 兵种 | 体型 | 武器 | 定位 | 来源 | 获取阶段 |
|------|------|------|------|------|----------|
| 士兵 | 中型 | 剑+盾 | 均衡近战 | 直接复用 | 初始 |
| 弓箭手 | 小型 | 弓 | 远程输出 | 直接复用 | 初始 |
| 骑士 | 大型 | 大剑+头盔 | 重装坦克 | 直接复用 | 第2章 |
| 枪兵 | 中型 | 伸缩长枪 | 中距近战 | 直接复用 | 第2章 |
| 王子/指挥官 | 中型 | 剑+光环 | 光环支援 | 修改复用(加光环) | 第3章 |

#### 精灵密林（4个 — 精锐少数，每个独特）

| 兵种 | 体型 | 武器 | 定位 | 来源 | 获取阶段 |
|------|------|------|------|------|----------|
| 月刃舞者 | 小型 | 双刀 | 快速刺客 | 修改复用(刺客→精灵版) | 援护远征 |
| 德鲁伊 | 中型 | 法杖(治疗弹) | 治疗支援 | 修改复用(魔法师→治疗) | 援护远征 |
| 游侠 | 小型 | 短弓 | 精准远程 | 新做 | 支线远征 |
| 树卫士 | 大型 | 木锤 | 自然坦克 | 新做 | 主线推进 |

#### 兽人部落（4个 — 粗犷暴力，以力服人）

| 兵种 | 体型 | 武器 | 定位 | 来源 | 获取阶段 |
|------|------|------|------|------|----------|
| 狂战士 | 中型 | 斧头 | 狂暴近战 | 直接复用 | 援护远征 |
| 战争首领 | 大型 | 巨斧 | 重装坦克+光环 | 修改复用(巨斧战士→加光环) | 援护远征 |
| 兽人战士 | 中型 | 棍棒→铁锤 | 高攻近战 | 新做 | 支线远征 |
| 猎头者 | 小型 | 投石索 | 远程减速 | 新做 | 支线远征 |

### UD3：升级路线 — 武器形态变化

所有兵种拥有4级升级路线（Lv1 → Lv3 → Lv6 → Lv9），每次升级改变武器/装备形态：

#### 人类王国

**士兵：** 短剑 → Lv3 +盾 → Lv6 +头盔 → Lv9 剑换精钢长剑

**弓箭手：** 单箭低准 → Lv3 三箭齐射 → Lv6 精准提升 → Lv9 穿甲箭

**骑士：** 长剑+头盔 → Lv3 +铁盾 → Lv6 全身板甲 → Lv9 剑换圣剑（带光效）

**枪兵：** 伸缩长枪 → Lv3 +头盔 → Lv6 +盾 → Lv9 枪头换三叉戟（范围增大）

**王子/指挥官：** 剑 → Lv3 +号令光环(友军攻+15%) → Lv6 +盔甲 → Lv9 光环升级(攻+25%，移速+10%)

#### 精灵密林

**月刃舞者：** 双刀 → Lv3 +第三把刀 → Lv6 旋转加速 → Lv9 刀刃附魔（攻击带微弱追踪）

**德鲁伊：** 单发治疗弹 → Lv3 双发治疗弹 → Lv6 追踪治疗 → Lv9 群体治疗波

**游侠：** 短弓 → Lv3 精准射击(高伤害单发) → Lv6 隐身射击(首击额外伤害) → Lv9 连珠箭

**树卫士：** 木锤 → Lv3 +藤甲 → Lv6 自然回血(每秒回1%HP) → Lv9 荆棘反伤(近战攻击者受伤)

#### 兽人部落

**狂战士：** 斧头 → Lv3 +头盔+自动冲刺 → Lv6 双斧+旋转 → Lv9 嗜血(击杀回血20%)

**战争首领：** 巨斧 → Lv3 +骨甲 → Lv6 战吼光环(友军攻速+20%) → Lv9 巨斧带击飞效果

**兽人战士：** 棍棒 → Lv3 +骨盾 → Lv6 棍棒换铁锤 → Lv9 碎甲攻击(降低目标防御)

**猎头者：** 投石索 → Lv3 +多石连发 → Lv6 毒石(附带减速) → Lv9 爆裂石(范围伤害+减速)

### UD4：升级与命名系统的同步

- Lv1-2：基础形态，"无名新兵"的脆弱感
- Lv3：第一次武器变化 = 获得名字的时刻，视觉辨识度开始
- Lv6：第二次变化，士兵已经历多次战斗，明显变强
- Lv9：终极形态，退役/英灵殿级别，"传说感"

Lv3获得名字时恰好第一次武器变化，玩家看到名字的同时看到外观变了，情感冲击最强。

### UD5：编队容量系统

```
出征容量 = 25点
  小型（弓箭手/月刃舞者/游侠/猎头者）= 1点
  中型（士兵/王子/枪兵/德鲁伊/狂战士/兽人战士）= 2点
  大型（骑士/树卫士/战争首领）= 3点
```

### UD6：工作量评估

```
13个兵种总计：
  直接复用（换皮+调参）：5个（士兵、弓箭手、骑士、枪兵、狂战士）
  修改复用（改行为+换皮）：4个（王子、刺客→月刃舞者、魔法师→德鲁伊、巨斧战士→战争首领）
  全新制作：4个（游侠、树卫士、兽人战士、猎头者）
```

## Themes and Patterns

1. **虚空腐蚀是万能叙事工具** — 解释了跨种族敌人、美术复用、道德框架，一个设定解决多个问题
2. **光与暗的对比** — 虚空不理解牺牲，同盟的牺牲精神恰恰是虚空无法理解也最害怕的力量
3. **体型即定位** — 小/中/大的物理差异天然形成克制关系，不需要复杂的数值克制表
4. **远征=解锁** — 世界观直接绑定到玩法进度，每次远征都有明确的"获得新兵种"期待
5. **武器变化=成长可视化** — 升级不只是数值变化，每次升级都有视觉反馈，与命名系统同步创造情感节点

## Session Summary

### Key Decisions

- 世界观深度为中量级，不追求完整历史线
- 虚空设定作为外部敌人，腐蚀机制解释跨种族敌人
- 种族关系纯粹团结，强调跨种族牺牲精神
- 地图纯叙事用途，不做地图玩法
- 13个兵种（人类5+精灵4+兽人4），覆盖5个直接复用+4个修改复用+4个新做
- 所有兵种4级升级路线，武器形态变化与命名系统同步

1. 设计主线叙事结构 — 几章？每章的剧情节奏？
2. 设计卡牌事件池 — 每个区域的基础事件模板
