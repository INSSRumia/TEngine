## Brainstorming Approach

**Selected Mode:** 引导式（Guided）

**Techniques Available:**
- MDA 框架探索、核心循环设计、玩家幻想挖掘、类型混搭

- 约束盒、参考融合、What If 场景
- 弹珠战斗世界观构建、养成系统设计、收集与成长曲线

**Focus Areas:**
- 弹珠物理战斗系统（核心）

## Core Direction

- **核心战斗：** 物理模拟驱动的弹珠自动战斗（参考 Marble Kingdoms），弹珠=士兵肉体，挂载武器/装备，通过物理碰撞战斗
- **外围方向：** 养成为主 — 收集不同种类士兵、Buff、道具，逐步积累成长
- **项目定位：** 保留弹珠战斗核心，重新设计外围玩法

## Ideas Generated

**[玩家幻想 #1]**: 将军/领袖 — 排兵布阵的指挥者
_Core Loop_: 玩家作为种族领袖，选择出征兵力、编队、决定行军路线，观看弹珠士兵在物理战场上自动战斗
_Novelty_: "搜打撤"式的兵力选择 — 带少量精锐以小博大，或大军碾压，风险与收益的自主博弈

**[世界观 #2]**: 经典西幻多种族世界
_Core Loop_: 玩家选择种族开局（人类/精灵/矮人/兽人/亡灵等），每个种族拥有独特兵种和不同的出征动机
_Novelty_: 不同种族给予不同的出征理由（资源争夺/威胁防卫/荣耀争夺/探索发现），混合驱动

**[核心循环 #3]**: Roguelike出征 + 永久养成
_Core Loop_: 编队 → 选关卡 → 卡牌抉择行军 → 弹珠物理战斗 → 带士兵回家 → 强化 → 再次出征
_Novelty_: 类杀戮尖塔结构，但核心战斗是物理模拟弹珠碰撞，出征中阵亡的士兵永久消失

**[行军系统 #4]**: 王权式卡牌抉择
_Core Loop_: 每次行军遇到随机事件，以卡牌形式呈现二选一决策（左/右），不同选择带来不同战斗、奖励或风险
_Novelty_: 轻量开发成本，叙事感强，"将军面对未知做决策"的幻想体验，每次出征体验不同

**[养成系统 #5]**: 战斗升级 + 基地成长
_Core Loop_: 士兵通过战斗获得经验升级，基地可解锁新兵种并提供出征初始加成
_Novelty_: 永久层仅保留士兵和基地，Buff/道具为单次出征临时效果，自然控制数值膨胀

**[数值制衡 #6]**: 难度分级 + 经验衰减
_Core Loop_: 不同关卡有不同难度，高级士兵打低级图经验大幅衰减，鼓励玩家挑战更高难度
_Novelty_: 允许"老兵带新兵"的刷级玩法，给稳妥型玩家一条安全成长路线

**[英灵殿 #7]**: 满级士兵退役系统
_Core Loop_: 士兵达到满级后可送入英灵殿，提供全队被动加成，阵亡后可免费复活一次（之后永久消失）
_Novelty_: 满级退役变成终极长期目标，退役士兵"先辈的祝福"提供永久光环加成

## Themes and Patterns

1. **风险与收益的自主博弈** — 贯穿兵力选择、关卡难度、行军决策、士兵保护
2. **永久层 vs 单次层的清晰分离** — 士兵和基地是永久的，Buff和道具是临时的
3. **"将军做决策"的幻想** — 编队、行军卡牌、兵力选择都是决策点的体现
4. **物理碰撞的观赏性** — 弹珠战斗本身是核心吸引力，适合短视频传播
5. **小体量友好设计** — Roguelike结构天然控制内容量，卡牌系统开发成本低

## Promising Combinations

- **兵力选择 + 经验衰减 + 老兵带新兵** = 一条完整的"安全发展"路线
- **卡牌抉择 + 永久死亡** = 每个决策都有重量感
- **英灵殿 + 基地兵种解锁** = 双重长期目标，驱动反复游玩

## Session Summary

### Most Promising Concepts

**Top Pick: Roguelike弹珠出征**
以弹珠物理战斗为核心的Roguelike出征系统，配合王权式卡牌行军决策和"搜打撤"兵力选择，形成独特的将军幻想体验。

**Runner-up: 英灵殿 + 满级退役系统**
满级士兵退役进入英灵殿并提供全队加成，为养成系统提供了终极长期目标，同时自然解决高等级士兵"无事可做"的问题。

**Honorable Mention: 经验衰减 + 难度分级**
简单有效的数值制衡手段，同时创造了"老兵带新兵"的玩法叙事，开发成本低但效果显著。

### Key Insights

- 弹珠物理战斗本身就有观赏性和传播性，外围系统应该服务于"让玩家反复观看弹珠战斗"这个核心
- 永久层和单次层的清晰分离是控制数值膨胀的关键设计决策
- 小游戏体量要求外围系统尽量轻量 — 卡牌式行军、经验衰减都是低成本高回报的设计
- 玩家的核心幻想是"将军做决策"而不是"亲自操作战斗"，这决定了游戏的交互重心在出征前和行军中
