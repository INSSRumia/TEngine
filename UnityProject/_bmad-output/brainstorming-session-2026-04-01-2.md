## Ideas Generated

### A1：Sensation（感官刺激）— 分层反馈系统

**[感官设计 #1]**: 分层碰撞反馈
_Core Loop_: 普通碰撞轻反馈（轻微音效+弹开）→ 击杀中反馈（死亡特效+击杀音效）→ 高光重反馈（慢动作+镜头拉近+爆裂特效）
_Novelty_: "安静让响亮更有力" — 平时克制反馈，关键时刻才爆发，让高光时刻真正有冲击力

**[感官设计 #2]**: 材质差异化碰撞
_Core Loop_: 不同材质弹珠（金属/木/石）碰撞时有不同的音效和视觉表现
_Novelty_: 物理本身就有美感，不需要额外粒子掩盖弹珠碰撞的优雅

**[感官设计 #3]**: 高光慢动作 + 镜头聚焦
_Core Loop_: 事件触发 → 瞬间暂停(0.05s) → 慢动作播放(0.2x) → 镜头平滑拉近 → 恢复正常
_Novelty_: 用 Time.timeScale 争取镜头移动时间，不需要预测碰撞；每场战斗限制慢动作次数避免滥用

### A2：Fantasy（幻想代入）— 将军存在感 + 士兵个性化

**[幻想设计 #4]**: 将军不参战，以战略技能形式存在
_Core Loop_: 将军在出征前/行军中/战斗中释放有限次数的战略技能（全军加速/回复HP/预知卡牌等），玩家既是旁观者又是干预者
_Novelty_: 不改变弹珠物理战斗核心，同时让将军有实际存在感和决策重量

**[幻想设计 #5]**: 命名系统 — 升级获得身份
_Core Loop_: 士兵升到一定等级(Lv2-3)后获得随机名字，名字显示在头顶（未命名只显示HP条），自然形成"消耗品"vs"核心资产"的情感分层
_Novelty_: "他只是一个无名新兵...如果他活下来，就会有自己的名字" — 命名门槛本身创造叙事张力

**[幻想设计 #6]**: 性格系统 = 随机Buff
_Core Loop_: 命名时随机分配不可更改的性格（勇猛+攻击/谨慎+防御/残暴+击杀后爆发/坚韧+一次复活/狡猾+优先低血量/忠诚+友军附近加防/孤狼+单兵加攻），每个命名士兵都独一无二
_Novelty_: 性格既是数值Buff又是叙事标签，轻量实现但大幅增强代入感

### A3：Narrative（叙事体验）— 数据追踪 + 故事生成

**[叙事设计 #7]**: 战斗关键数据追踪
_Core Loop_: 记录个人数据（击杀数/承伤/造成伤害/存活场次）+ 战役数据（总战斗/总击杀/总死亡/事件选择）+ 特殊时刻判定（首杀/以弱胜强/绝地反击/一骑当千/最后一人/零伤亡/全军覆没/老兵不死/传承）
_Novelty_: 用规则引擎实时判定高光等级（普通/稀有/史诗/传奇），不需要人工干预

**[叙事设计 #8]**: 出征报告 + 故事模板
_Core Loop_: 每次出征结束生成结构化报告（存活数/击杀数/战役亮点/老兵语录），亮点从预设故事模板中匹配生成
_Novelty_: 程序化叙事 — 不需要手写剧情，战斗数据自动生成独特故事

### A4：Submission（沉浸投入）— 距离分级 + 快速启动

**[沉浸设计 #9]**: 距离决定战斗数量
_Core Loop_: 近郊巡逻(3-4场/~10min) → 区域征伐(5-7场/~20min) → 远征讨伐(8-10场/~30min) → 传说远征(10-12场/~40min)，玩家自主选择节奏
_Novelty_: 距离本身有叙事感（越远越危险但宝藏越多），同时让玩家根据可用时间选择出征长度

**[沉浸设计 #10]**: 最小决策出征（不加补给系统）
_Core Loop_: 出征前只做两个决策 — 带谁 + 去多远，立刻开打
_Novelty_: 减少出征前认知负担 = 提高"再来一把"意愿，适合小游戏定位

**[沉浸设计 #11]**: 失败钩子
_Core Loop_: 出征失败时解锁新卡牌事件/获得远征情报，让失败也有收获感
_Novelty_: "差一点就赢了" + 失败也有奖励 = 最强的再来一把驱动力

### A5：Failure State（失败状态设计）— 四档结局 + 撤退系统

**Technique Used: 失败状态设计（Failure State Design）**

**[失败设计 #12]**: 命名/未命名的死亡叙事分层
_Core Loop_: 未命名士兵死亡 — 快速碎裂，无特殊处理；命名士兵死亡 — 慢动作 + 英雄陨落音效 + 文字提示（"亚瑟倒在了第4场战斗中"）+ 记入英烈祠
_Novelty_: 对比本身就是叙事 — 未命名像炮灰默默消失，命名士兵的死是一个事件，让玩家渴望"让他们活到获得名字的那一天"

**[失败设计 #13]**: 英烈祠 — 阵亡记录系统
_Core Loop_: 基地中记录所有阵亡的命名士兵，显示姓名、等级、存活场次、击杀数、死亡场景
_Novelty_: 轻量实现但情感价值高，让死亡不只是一个数字归零而是被记住

**[失败设计 #14]**: 遗物/传承系统（可选）
_Core Loop_: 命名士兵死亡后留下"遗物"（Buff），装备给其他士兵时获得该性格的加成
_Novelty_: "他倒下了，但他的勇气留了下来" — 死亡转化为传承，进一步降低玩家的挫败感

**[失败设计 #15]**: 四档战斗结局
_Core Loop_: 完美胜利（全灭敌人，零伤亡）→ 惨胜（全灭敌人，有伤亡）→ 撤退（部分士兵撤回，放弃战斗奖励）→ 全军覆没（零撤回，出征临时资源丢失）
_Novelty_: 撤退本身也分好坏 — 撤回8/10是"成功撤退"，撤回1/10是"几乎全灭"，不是简单的二分结果

**[失败设计 #16]**: 边界撤退机制
_Core Loop_: 玩家随时可点撤退，弹珠获得撤退标记（头顶显示逃跑图标），碰到己方边界时撤出；敌人继续追击，被包围的弹珠可能在撤退途中阵亡；撤回的士兵保留当前HP/经验状态
_Novelty_: 撤退成功率取决于弹珠在战场上的位置 — 不是所有士兵都能跑掉，物理碰撞和AI行为决定了谁生谁死，"跑啊亚瑟！只剩最后一格了！"

**[失败设计 #17]**: 撤退AI优化（待定）
_Core Loop_: 撤退标记激活后，弹珠AI从"追击最近敌人"变为"向己方边界移动，但遇到敌人时仍然战斗" — 边打边撤
_Novelty_: 被包围的弹珠依然很难逃（敌人挡路），不被包围的有机会；玩家觉得"我尽力了"而不是"完全看运气"；开发成本极低（改AI目标点）

## Themes and Patterns

1. **分层是核心设计语言** — 反馈分层、情感分层（未命名/命名）、距离分层、高光分层
2. **程序化叙事** — 不手写剧情，用数据+规则引擎自动生成独特故事体验
3. **克制带来冲击力** — 普通时刻克制，高光时刻爆发，感官体验如此，叙事也如此
4. **最小决策原则** — 小游戏的核心，每个决策点都必须简洁直觉
5. **Time.timeScale 是万能工具** — 慢动作解决镜头问题、高光呈现问题、观战体验问题
6. **失败即内容** — 死亡不是惩罚，而是叙事素材；四档结局比二分结果更有层次
7. **撤退是最有趣的失败** — 不是"赢了"或"输了"，而是"我能救回多少人"

## Technical Feasibility Notes

- **高光判定：** 规则引擎 + 击杀事件触发，复用已有 EventManager，复杂度低
- **镜头系统：** 瞬间暂停 → 慢动作 → 镜头移动，核心是 Time.timeScale + CameraController
- **叙事系统：** 数据追踪 + 模板匹配，首发可只实现5-6个预设模板
- **命名系统：** 随机名字池 + 等级触发 + 头顶UI显示，实现简单
- **建议首发不做：** 回放缓冲（RenderTexture）、过多粒子特效、复杂补给系统

## Session Summary

### Most Promising Concepts

**Top Pick: 命名 + 性格系统**
最小成本实现最大情感收益。命名门槛自然创造叙事张力，性格Buff同时服务数值和叙事，每个士兵都独一无二。

**Runner-up: 分层反馈 + 高光慢动作**
Time.timeScale 方案优雅简洁，不需要预测碰撞，实现复杂度低但观感提升巨大。

**Runner-up: 边界撤退机制**
"碰到边界才能撤出" + 敌人追击 = 天然的撤退戏剧性，创造"我能救回多少人"的核心张力。四档战斗结局让失败也成为有意义的内容。

**Honorable Mention: 距离分级出征**
让玩家自主选择游戏节奏，同时创造"越远越危险"的直觉叙事，一个机制解决多个问题。

### Key Insights

- MDA 审视确认了四个目标情感都有机制支撑，暂无明显缺口
- 小游戏设计的关键是"减法" — 补给系统砍掉是正确决策
- 技术上所有设计都有成熟的 Unity 实现方案，无重大技术风险
- 程序化叙事（数据+模板）比手写剧情更适合 Roguelike 的重玩性需求
- 失败状态设计的核心发现：命名/未命名的死亡分层 + 边界撤退机制 = 死亡不只是惩罚，而是叙事素材
- 现有项目的撤退机制（边界触碰撤出）天然适配新游戏，且比战斗间撤退更有戏剧性
