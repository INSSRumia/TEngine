## Design Decisions

### D1：技能介入深度

- 轻介入和重介入技能并存
- 玩家不频繁操作，每场战斗约3次操作机会
- 无目标技能（增益/地形/召唤，一键释放）+ 有目标技能（点击选择目标后释放）混合

### D2：技能次数分离

- 行军技能和战斗技能分开计算
- 互不挤占，各司其职

### D3：技能获取方式

- 固定技能组，无成长/解锁系统
- 种族 = 将军 = 技能组，选择种族即锁定战术风格
- 最简实现，适合小游戏首发

### D4：种族差异

- 不同种族将军拥有完全不同的技能组
- 围绕种族核心主题设计技能，风格鲜明

### D5：行军技能冷却机制

- 行军技能使用"事件冷却制"：使用后需经过N个卡牌事件才能再次使用
- 天然解决远征距离缩放问题：长距离远征 = 更多技能使用机会
- CD值分级：CD2（轻量工具）、CD3（中等强度）、CD4（投资技能）、CD5（终极技能）

### D6：战斗技能次数

- 每场战斗每个技能可用1次
- 每个种族3个战斗技能，全场共3次操作机会

### D7：首发种族数量

- 首发做3个种族：人类王国、精灵密林、兽人部落
- 覆盖均衡/操作/激进三种核心体验
- 矮人堡垒和亡灵军团已设计，预留后续更新

## Final Design: 将军技能系统

### 系统框架

```
选择种族 → 固定技能组
├── 行军技能 ×3（事件冷却制：经过N个卡牌事件后可用）
└── 战斗技能 ×3（每场每个技能可用1次，全场共3次操作）
```

**战斗技能（每场各1次）：**

|------|------|------|

## Themes and Patterns

1. **种族=将军=技能组** — 一选定终身，无需额外搭配，最简设计
2. **事件冷却是优雅的缩放机制** — 不需要为不同距离配置不同次数，自然适配
3. **3次操作是甜蜜点** — 足够有参与感，不打破观战沉浸
4. **有目标技能是参与感的来源** — 选择谁治疗/谁攻击，比一键释放更有"将军做决策"的感觉
5. **预留扩展不影响首发** — 矮人和亡灵已设计完毕，随时可加入

## Session Summary

### Key Decisions

- 将军不参战，以战略技能存在，兼顾战斗参与感和行军沉浸感
- 行军技能采用事件冷却制，战斗技能每场各1次
- 固定技能组，种族选择即技能选择，无成长系统
- 首发人类+精灵+兽人，预留矮人+亡灵
