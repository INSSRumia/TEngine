### 发射物系统 (Projectile Module)

发射物是远程攻击的核心载体，独立于 Marble 生命周期管理，通过 Ability 组合实现不同效果。

**架构：**
- `Projectile` 继承 `ASC<ProjectileRuntimeData>`，核心实体类
- `ProjectileFactory` 静态工厂，根据配置创建发射物
- `ProjectileRuntimeData` 运行时数据，含 SourceCamp/TargetMarbleInstId/追踪模式等
- 通过 `IOnTriggerEnter` 接口处理碰撞
- 使用 HashSet<int> 记录已命中目标实现穿透

**追踪模式（EnumProjectileTrackingMode）：**
- None = 0：直线飞行
- Target = 1：追踪目标 Marble
- Point = 2：追踪固定坐标点

**核心 Ability（自动挂载）：**
- `ProjectileMoveAbility`：IAbilityFixedUpdate，直线/追踪飞行，转向速率限制
- `ProjectileDamageAbility`：IOnTriggerEnter，碰撞伤害，穿透计数
- `ProjectileLifetimeAbility`：IAbilityUpdate，MaxLifetime 倒计时，超时自动 Despawn

**发射能力：**
- `WeaponFireAbility`：Equipment Ability 基类，封装冷却管理和射击间隔
- `BowFireAbility`：继承 WeaponFireAbility，支持连射和散射模式

**敌我判断：**
- Projectile 不注册到 CombatManager
- 通过 SourceCamp 进行敌我判断（碰撞时对比阵营）

基础功能:
1. 受伤
2. 治疗
3. 死亡
4. 移动
5. 旋转

核心随时触发的能力:
属性: BasePendingDamage, DamageAddition, DamageMultiplier, FinalDamage, Defense, Hp, MaxHp, Shield, MaxShield

1.  被攻击的能力(随时触发):IReceiveDamage
    - 将伤害添加到BasePendingDamage

    - 获取所有IAfterReceiveDamage的Ability并执行

    - 触发计算伤害的能力

2.  计算伤害的能力(随时触发)
    - 计算伤害 FinalDamage = (BasePendingDamage * DamageMultiplier) + DamageAddition - Defense

    - 获取所有IAfterCalculateDamage的Ability并执行

    - 如果FinalDamage > 0 触发应用伤害的能力

3.  应用伤害的能力(随时触发)
    - 应用伤害

    if(Shield > 0){
        Shield = Mathf.Max(Shield - FinalDamage, 0);
        return;
    }
    Hp = Mathf.Max(Hp - FinalDamage, 0);
    
    - 如果不再是满血，移除满血Tag

    - 获取所有IAfterApplyDamage的Ability并执行

    - 如果Hp <= 0 触发死亡的能力

4.  死亡能力(随时触发)
    - 处理死亡逻辑 IsAlive = false;

    - 添加死亡Tag

    - 获取所有IAfterDeath的Ability并执行

5.  被治疗的能力(随时触发):IReceiveHeal
    - 将治疗添加到BasePendingHeal

    - 获取所有IAfterReceiveHeal的Ability并执行

    - 触发计算治疗的能力

6.  计算治疗量的能力(随时触发)
    - 计算治疗量 FinalHeal = (BasePendingHeal * HealMultiplier) + HealAddition

    - 获取所有IAfterCalculateHeal的Ability并执行

    - 如果FinalHeal > 0 触发应用治疗的能力

7.  应用治疗的能力(随时触发)

    Hp = Mathf.Min(Hp + FinalHeal, MaxHp);
    
    - 如果满血了，添加满血Tag

    - 获取所有IAfterApplyHeal的Ability并执行

8.  被添加护盾值的能力(随时触发)
    - 将护盾值添加到BasePendingShield

    - 获取所有IAfterReceive的Ability并执行

    - 触发计算添加护盾值的能力

9.  计算添加护盾值的能力(随时触发)
    - 计算护盾值 FinalShield = (BasePendingShield * ShieldMultiplier) + ShieldAddition

    - 获取所有IAfterCalculateShield的Ability并执行

    - 如果FinalShield > 0 触发应用护盾的能力

10. 应用护盾的能力(随时触发)

    Shield = Mathf.Min(Shield + FinalShield, MaxShield);
    
    - 如果满盾了，添加满盾Tag

    - 获取所有IAfterApplyShield的Ability并执行

核心FixedUpdate能力:

1.  移动能力 优先级0
    - 属性: (float)MoveSpeed, (float)Acceleration, (Vector2)TargetDir

    - 获取当前速度: RigidbodyVelocity

    - 计算目标速度: TargetVelocity = TargetDir * MoveSpeed

    - 计算施力方向: ForceDir = (TargetVelocity - CurrentVelocity).normalized

    - 计算力的大小: ForceMagnitude = Acceleration * Rigidbody.mass

    - 计算冲量: Impulse = ForceDir  ForceMagnitude  Time.fixedDeltaTime

    - 应用冲量: Rigidbody.AddForce(Impulse, ForceMode.Impulse);

2.  旋转能力 优先级0
    - 属性: (float)RotateSpeed, (float)AngularAcceleration, (RotateDir

    - 获取当前角速度: Rigidbody.angularVelocity

    - 计算目标角速度: TargetAngularVelocity = RotateDir * RotateSpeed;

    - 计算施力方向: TorqueDir = Mathf.Sign(TargetAngularVelocity - CurrentAngularVelocity)

    - 计算力的大小: TorqueMagnitude = AngularAcceleration * Rigidbody.inertia;

    - 计算冲量: AngularImpulse = TorqueDir  TorqueMagnitude  Time.fixedDeltaTime;

    - 应用冲量: Rigidbody.AddTorque(AngularImpulse, ForceMode.Impulse);

附加FixedUpdate能力:

1.  索敌能力 优先级90000 (目前只做寻找最近的敌人，最近的敌人通过战斗管理器获取，战斗管理器会在其他线程统一计算最近的敌人): IFindTarget
    - 获取最近的敌人: EnemyManager.GetNearestEnemy(transform.position)

    - 将敌人的Uid存到RuntimeData中，将敌人的引用存在自己的字段中，IFindTarget提供一个属性用来获取敌人。

2.  行为逻辑能力 优先级80000 (可以制作各种行为逻辑，也可以同时拥有多个行为逻辑)
    - 行为逻辑能力通过改变MoveSpeed, Acceleration, TargetDir, RotateSpeed, AngularAcceleration, RotateDir来实现各种行为。

    - 例如待在敌人3个单位范围内的行为逻辑(近战)，可以在距离Target 大于3个单位时触发，将TargetDir设置为指向敌人的方向。

    - 例如待在敌人5个单位范围外的行为逻辑(远程)，可以在距离Target 小于5个单位时触发，将TargetDir设置为远离敌人的方向。

    - 例如一个冲刺的行为力有逻辑，有一个冷却时间，当逻辑冷却完成后，可以提高MoveSpeedAddition和AccelerationAddition或者 MoveSpeedMultiplier和AccelerationMultiplier。

    - 例如一个用盾或者武器冲击敌人的行为逻辑，可以通过控制RotateDir，让球转到盾面向敌人，然后提高速度和加速度冲向敌人。

    - 例如逃跑的行为逻辑，当目标敌人距离大于3个单位时，将TargetDir 指向逃跑的方向

    - ability可以被随时添加和移除
