# 远征事件设计 第一批

本文档基于 [gdd.md](D:\UnityProject\Marbles Legion\_bmad-output\gdd.md) 中的以下设计目标整理：

- 卡牌事件是远征中的核心二选一抉择
- 事件要服务于风险换收益，而不是单纯发数值
- 失败也要有收获，事件池应当支持补员、恢复、情报与叙事回报
- 事件要强化西幻远征、虚空侵蚀、同盟行军、英魂叙事这些世界观气质

当前这批事件只使用已经实现的 Effect：

- `AddMoneyEffect`
- `AddPlayerMarbleHpEffect`
- `AddPlayerMarbleExpEffect`
- `AddPlayerMarbleEffect`
- `ChangeEnvironmentEffect`

这意味着它们可以在当前系统里直接配置，不依赖未来的 Buff、Item、Flag 或动态插入逻辑。

## 1. 使用建议

- 每个事件默认设计为两个选项，符合当前主循环和 GDD 的“二选一”节奏。
- `summary` 建议直接写成玩家可读文本，方便当前 Summary 系统复用。
- 文中的 `forest_env`、`road_env`、`void_env`、`human_militia` 一类字段是占位符，需要替换成你项目里的实际配置 Id。
- 招募类事件建议优先使用“人类民兵 / 精灵游侠 / 兽人战士”这类低中阶单位，避免事件直接发太强的兵。

## 3. 事件清单

## 3.1 `evt_supply_cart`

`title`：迷路的补给车  
`description`：道路旁翻倒着一辆同盟补给车，车轮已经断裂，周围散落着还未被虚空傀儡带走的木箱。继续前进之前，你们可以花一点时间搜刮这批物资。

### Option A

`option_id`：take_safe  
`title`：收集还能用的物资  
`description`：只拿最外层容易搬走的补给，尽快离开这片区域。

建议 Effect：

- `AddMoneyEffect(summary="收集了部分补给，获得 30 money。", money_delta=30)`

### Option B

`option_id`：search_hidden  
`title`：仔细翻找暗格  
`description`：撬开箱底和车厢夹层，看看有没有更值钱的东西，但这会拖慢行军。

建议 Effect：

- `AddMoneyEffect(summary="翻出隐藏物资，获得 60 money。", money_delta=60)`
- `AddPlayerMarbleHpEffect(summary="长时间搬运和警戒让全队有些疲惫。", hp_delta=-6)`

设计意图：

- 标准的“安全小赚 vs 风险大赚”
- 适合做 common pool 基础事件

## 3.2 `evt_tired_march`

`title`：疲惫的行军  
`description`：连续几天的急行军让不少士兵气息紊乱，前方正好有一处废弃营地。这里可以短暂停留，但也意味着放缓推进节奏。

### Option A

`option_id`：make_camp  
`title`：原地整顿  
`description`：升火、扎营、处理伤口，让部队以更稳的状态继续前进。

建议 Effect：

- `AddPlayerMarbleHpEffect(summary="短暂休整后，全队恢复了体力。", hp_delta=12)`

### Option B

`option_id`：push_forward  
`title`：继续推进  
`description`：不做停留，保持军心和行军节奏，尽快接近目标。

建议 Effect：

- `AddPlayerMarbleExpEffect(summary="强行推进让士兵们积累了宝贵的行军经验。", exp_delta=10)`

设计意图：

- 这是“保血线 vs 抢成长”的基础抉择
- 非常适合插在战斗前 1 到 2 个节点的位置

## 3.3 `evt_refugee_boy`

`title`：流民少年  
`description`：一个背着破布包的少年从路边灌木中钻出，自称曾在边境军里打杂，愿意跟着你们行动，只求一口吃的和一柄能用的武器。

### Option A

`option_id`：accept  
`title`：收留他  
`description`：让他编入队伍，也许他能在真正的战场上派上用场。

建议 Effect：

- `AddPlayerMarbleEffect(summary="队伍接纳了一名年轻的追随者。", marble_spawn_config={ marble_config_id=\"human_militia\", level=1, camp_config_id=\"human_kingdom\" }, count=1)`

### Option B

`option_id`：give_coin  
`title`：给些盘缠  
`description`：不把他带上战场，但给他一点钱和口粮，让他有机会活下去。

建议 Effect：

- `AddMoneyEffect(summary="你花了一笔钱安置了少年。", money_delta=-20)`
- `AddPlayerMarbleExpEffect(summary="这次决定让士兵们意识到同盟远征不只是杀敌。", exp_delta=6)`

设计意图：

- 这是第一批事件里最适合做“温和招募”的范本
- 也把世界观中的同盟责任感带了出来

## 4. 下一步推荐

如果你要继续往下推进，我建议按这个顺序做：

1. 先从上面 12 个里挑 6 个，做成第一批真正入表的基础事件
2. 其中至少保留 2 个招募事件，让 `AddPlayerMarbleEffect` 真正进入实际循环
3. 至少保留 2 个环境切换事件，尽快让环境系统开始“说话”
4. 虚空风险事件不要一开始放太多，否则早期远征会过度偏向掉血换钱

如果你愿意，我下一步可以继续直接帮你把这份文档进一步压成“填表稿”，也就是每个事件改写成更接近 `expedition_event.xlsx` 的行结构。
