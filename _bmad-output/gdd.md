# Marble Legion（弹珠军团）- Game Design Document

**Author:** INSS_
**Game Type:** Roguelike（轻量级）
**Target Platform(s):** PC (Steam), 后续扩展移动端/小游戏

---

## Executive Summary

### 游戏名称

Marble Legion（弹珠军团）

### 核心概念

Marble Legion 是一款弹珠物理战斗驱动的 Roguelike 策略养成游戏。玩家作为同盟将军，带领不同种族的士兵踏上对抗虚空侵蚀的远征。经典西幻世界中，虚空裂隙正在大陆各处打开，腐化生灵变为没有自我意志的傀儡。人类、精灵、兽人三大种族结成纯粹的同盟，玩家选择种族即锁定将军技能风格，但可招募所有种族的士兵组成混合军队。

核心玩法循环为"编队出征 → 卡牌事件决策 → 弹珠物理混战观战与将军技能干预 → 士兵升级成长 → 基地积累 → 更强编队再次出征"。战斗是弹珠间的物理碰撞——士兵是弹珠，武器、盾牌、帽子是挂载部件，通过物理碰撞自动战斗，玩家通过释放将军战略技能（每场3次操作机会）和决定撤退时机进行轻量干预。

士兵在 Lv3 获得随机名字和不可更改的性格 Buff（如勇猛+攻击、坚韧+一次复活等），每次升级改变武器形态（Lv1→Lv3→Lv6→Lv9），Lv9 满级可送入英灵殿提供全队被动加成。命名士兵的阵亡会触发慢动作和英雄陨落音效，记入英烈祠，死亡转化为叙事素材而非纯粹的惩罚。

游戏首发3个种族（人类王国、精灵密林、兽人部落）共13个兵种，远征距离分4档（近郊巡逻~10min 到传说远征~40min），支持 PC（Steam）首发，后续扩展移动端和小游戏平台。

### 游戏类型

**类型：** Roguelike（轻量级）
**框架：** 本 GDD 使用 roguelike 模板，包含 Run 结构、过程生成、永久死亡与进度、道具与升级系统、角色选择、难度修正等类型专属章节。Roguelike 在本游戏中作为提供随机性和重玩性的手段，而非核心卖点。

## 目标受众

### 核心受众

15-30 岁核心及轻度策略玩家，对弹珠物理混战的观赏性和"将军做决策"的幻想体验有兴趣。

### 游戏经验

核心玩家为主，轻度玩家可通过自动战斗模式轻松上手。无需 Roguelike 经验，Roguelike 仅作为提供随机性的手段而非核心卖点。

### 游玩节奏

碎片时间（通勤、摸鱼）可进行低难度短远征（~10min）；晚间/周末进行高难度长远征（~40min）。距离分4档，玩家自主选择节奏。

### 次要受众

| 受众类型 | 特征 | 转化策略 |
|----------|------|----------|
| 短视频发现型玩家 | 被弹珠混战短视频吸引，以"看弹珠打架"为初始动机 | 极低学习门槛，首场战斗1分钟内展现弹珠碰撞精彩 |
| 放置/挂机玩家 | 享受部署后观看战斗结果的体验 | 轻量自动战斗，军队成长的满足感 |
| 叙事向玩家 | 被士兵命名与阵亡叙事、王权式决策的故事性所吸引 | 类似《Reigns》《Rogue Legacy》的受众 |

### 玩家核心动机

- 弹珠物理碰撞的视觉观赏性（首要动机）
- "将军做决策"的幻想体验（编队、技能、事件选择）
- 士兵命名与成长的情感连接

## 目标与背景

### 项目目标

| 优先级 | 类型 | 目标 | 说明 |
|--------|------|------|------|
| 1 | 创意/玩家影响 | 做出一款被玩家真心喜爱的作品 | 有人愿意为之停留、为之兴奋，是对创作者最好的回报 |
| 2 | 商业 | 通过短视频自然传播实现首发曝光 | 弹珠战斗视觉冲击力自带传播属性，降低获客成本 |
| 3 | 社区 | 积累初期社区和玩家反馈渠道 | B站/抖音账号 + 玩家交流，建立长期内容渠道 |
| 4 | 验证 | 验证"弹珠混战视频观众→游戏玩家"转化路径 | Marble Kingdoms 观众到玩家的转化，为后续运营提供依据 |

### 背景与动机

YouTube 上的 Marble Kingdoms 系列视频积累了大量播放，证明弹珠物理混战有巨大的观赏受众，但市面上尚无将这一体验转化为可玩游戏的产品。Marble Legion 直接填补这一空白——从"观看者"变成"指挥者"。

作为个人独立开发者，程序开发是核心能力，AI 工具大幅降低了美术和音效的门槛，使一人完成全流程成为可能。个人业余时间开发、零预算自费，核心约束是时间和质量，因此严格控制范围（MVP 优先）是关键策略。

## 独特卖点（USPs）

1. **弹珠物理混战的可玩化** — Marble Kingdoms 证明了弹珠混战的观赏受众规模，Marble Legion 首次将这一体验转化为可玩游戏，从观看者变成指挥者，有养成和决策深度
2. **观赏性优先的设计哲学** — 战斗本身是内容，所有系统服务于让战斗"好看"，弹珠碰撞的视觉奇观是核心吸引力，天然适合短视频传播，降低获客成本
3. **命名士兵的生死叙事** — 士兵 Lv3 获得名字和性格，每个命名士兵都独一无二；死亡不是数字归零而是被记住的故事，记入英烈祠，涌现式叙事让每次远征都创造独特回忆
4. **将军幻想的轻量介入** — 不是亲自操控战斗，而是编队选择、将军技能释放（每场3次操作）、撤退时机决定，"部署+观战"的参与模式提供"我在指挥"的感觉而不打破观战沉浸

### 竞争定位

| 对比维度 | 竞品 | Marble Legion 的差异 |
|----------|------|---------------------|
| 弹珠认知 | Marble Kingdoms 视频 | 从被动观看变为主动参与，有养成和决策深度 |
| 部署+观战 | 自走棋/放置类手游 | 物理碰撞的视觉奇观是独特卖点 |
| 碎片时间 | 幸存者类/轻度手游 | 3分钟内到达爽感，灵活的参与深度 |
| 叙事情感 | Reigns/Rogue Legacy | 命名士兵的生死叙事是差异化优势 |

## 核心玩法

### 游戏支柱

| 优先级 | 支柱 | 说明 |
|--------|------|------|
| 1（最高） | **弹珠观赏性** | 物理碰撞的视觉奇观是核心吸引力，所有系统必须服务于让战斗"好看" |
| 2 | **局外养成** | 士兵的成长与基地的发展是驱动玩家反复游玩的长期动力 |
| 3 | **决策参与感** | 将军技能释放、事件抉择、撤退时机让玩家有"我在指挥"的感觉 |
| 3 | **Roguelike** | 事件链的随机性提供每次不同的远征体验，是手段而非卖点 |

**支柱冲突原则：** 当支柱之间产生冲突时，优先级为：观赏性 > 养成 > 参与感 = Roguelike。如果某个系统让战斗更精彩但削弱策略深度，选择战斗。

### 核心游戏循环

```
编队出征（带谁 + 去多远）
  → 卡牌事件决策（行军中的随机事件，二选一）
    → 弹珠物理战斗（观战 + 将军技能轻量干预）
      → 士兵升级成长（经验、命名、武器形态变化）
        → 基地积累（解锁兵种、英灵殿加成）
          → 更强编队再次出征
```

**循环时长：** 单次远征 10~40 分钟（4档距离），长期循环跨越多次远征

**每次迭代的不同之处：** 不同的随机卡牌事件、不同的敌人组合、不同的士兵成长路径、不同的将军技能使用时机

### 胜负条件

#### 四档战斗结局

| 结局 | 条件 | 结果 |
|------|------|------|
| 完美胜利 | 全灭敌人，零伤亡 | 最大奖励 + 远征完美评级 |
| 惨胜 | 全灭敌人，有伤亡 | 正常奖励 + 战损报告 |
| 撤退 | 部分士兵撤出，放弃战斗奖励 | 撤回士兵保留HP/经验状态，直接结束本次远征 |
| 全军覆没 | 零撤回 | 出征临时资源丢失，永久士兵阵亡记入英烈祠 |

#### 撤退机制

玩家随时可点撤退，弹珠获得撤退标记向己方边界移动，碰到边界时撤出。撤回的士兵保留当前 HP/经验状态。**撤退直接结束本次远征**，机会成本为放弃当前战斗及后续所有战斗的奖励。撤退不施加额外压力（无追击机制、无腐蚀区域），玩家可自由选择撤退作为资源获取策略。

#### 失败恢复

- 阵亡士兵永久消失（命名士兵触发慢动作英雄陨落叙事，记入英烈祠）
- 基地和永久养成不受影响
- **英魂重临机制：** 全军覆没时记录该次远征；当玩家再次进行同一条远征路线时，有概率触发特殊事件——遇到上一次全军覆没中有名字的士兵的英魂。英魂临时加入当前远征队伍参与战斗，远征结束后离开。每条远征路线最多可积累一名英魂事件（取最近一次覆没中的随机一名命名士兵）
- 失败时解锁新卡牌事件/远征情报，让失败也有收获感

## 游戏机制

### 主要机制

| # | 机制类别 | 核心动词 | 说明 | 支撑支柱 |
|---|---------|---------|------|---------|
| 1 | **编队** | 选择、组合 | 出征前选择带哪些士兵、决定远征距离 | 参与感 |
| 2 | **卡牌事件** | 选择（二选一） | 行军中遇到随机事件，选择不同分支带来不同风险/收益 | Roguelike |
| 3 | **将军技能** | 释放（每场3次）、选目标 | 弹珠战斗中释放战略技能（治疗、加速、增伤等），选择目标位置或友军 | 参与感 |
| 4 | **撤退决策** | 决定撤退、观察局势 | 观察战场形势决定何时撤退，撤回士兵保留状态 | 参与感 |
| 5 | **弹珠战斗（自动）** | 观看 | 士兵弹珠自动物理碰撞战斗，玩家观看 | 观赏性 |
| 6 | **士兵养成** | 升级、命名、送入英灵殿 | 士兵获取经验升级，Lv3命名+性格，Lv9送入英灵殿 | 养成 |
| 7 | **基地管理** | 建造、解锁 | 永久养成系统，解锁新兵种、升级设施 | 养成 |

### 机制交互

- 编队（1）决定了战斗（5）中的军队构成
- 卡牌事件（2）为战斗（5）提供临时 Buff/Debuff
- 将军技能（3）直接影响战斗（5）的走向
- 战斗（5）结果驱动士兵养成（6）
- 养成（6）+ 基地（7）反过来扩展编队（1）的选择空间

### 机制演进

- **将军技能：** 种族决定技能风格（3种族×技能组），随远征进度解锁更多技能槽位
- **卡牌事件池：** 失败解锁新事件，事件池随游戏进程逐步丰富
- **士兵养成：** Lv1→Lv3→Lv6→Lv9 每个阶段解锁武器形态变化和新能力
- **基地：** 初始有限兵种，逐步解锁全部13个兵种

## 控制与输入

### 控制方案（PC / Steam）

| 操作 | 输入方式 | 说明 |
|------|---------|------|
| 远征准备 | 鼠标点击/拖拽 | 选择士兵、选择距离、查看兵种信息 |
| 卡牌事件 | 鼠标点击 | 二选一，点击选择事件分支 |
| 将军技能 | 数字键 1-3 + 鼠标点击 | 按键选技能，点击选目标位置/友军 |
| 撤退 | Esc / 屏幕按钮 | 任何时刻可触发撤退 |
| 战斗观战 | 鼠标拖拽平移 / 滚轮缩放 | 自由观看战斗，类似观战系统 |
| 基地管理 | 鼠标点击 | UI面板操作 |

### 小游戏/移动端触摸适配

游戏核心为"观战为主+轻量干预"，每场仅3次技能操作，触摸操作天然友好。主要适配点：

| 操作 | PC | 触摸适配 | 复杂度变化 |
|------|-----|---------|-----------|
| 将军技能 | 数字键+鼠标 | 底部技能栏点选 → 战场点击释放 | 多一步，完全可接受 |
| 其他操作 | 鼠标 | 点击/拖拽/双指缩放 | 无差异 |

### 输入手感

- **战斗观战：** 流畅的镜头跟随和自由平移/缩放，重点确保弹珠碰撞的视觉冲击力不受操作干扰
- **技能释放：** 选技能→选目标的两步操作需有清晰的视觉反馈（技能高亮→目标预览→释放特效），"干脆利落"的手感
- **卡牌事件：** 大面积点击区域，二选一不纠结，选中即生效

## Roguelike 专属设计

### 远征结构（Run Structure）

**Run = 远征**，一次远征就是一局游戏。

- **远征长度：** 4档距离（近郊巡逻~10min / 野外探索~20min / 深入腹地~30min / 传说远征~40min）
- **远征节奏：** 约 4~5 个卡牌事件后经历一场战斗，距离越远事件和战斗轮次越多
- **起始条件：** 从基地出发，编队选择士兵（受基地已解锁兵种限制）
- **难度递增：** 距离越远，敌人越强，事件越凶险，但奖励也越丰厚
- **胜利条件：** 完成远征最终战斗（Boss战或攻城战）
- **终止条件：** 胜利、撤退（玩家主动）、全军覆没

### 过程生成（Procedural Generation）

本游戏不做关卡生成，随机性来自卡牌事件链和敌人组合：

- **事件生成：** 从卡牌事件池中随机抽取，事件顺序随机排列，每 4~5 个事件后插入一场战斗
- **敌人组合：** 基于**战力预算系统**——每场战斗有一个"敌人战力预算" = 基础值 × 远征距离系数 × 战斗序号递增。不同兵种消耗不同预算（精英单位占更多），系统在预算范围内随机组合敌人，保证随机性的同时控制总强度
- **种子系统：** 无需确定性种子，每次远征独立随机

### 永久死亡与进度（Permadeath & Progression）

- **永久死亡：** 命名士兵（Lv3+）阵亡不可恢复，触发慢动作英雄陨落叙事，记入英烈祠
- **局间持久化：** 基地永久养成、解锁兵种、英灵殿加成、英魂重临机制（详见核心玩法-失败恢复）
- **元进度：** 失败解锁新卡牌事件和远征情报，让每次失败都有收获感

### 道具与升级系统（Item & Upgrade）

#### 临时 Buff（仅持续当前远征）

卡牌事件获得，**三档稀有度：**

**普通（绿色）— 纯正面，无风险：**

| Buff | 效果 |
|------|------|
| 强化攻击 | 攻击力+20% |
| 坚韧体质 | HP+30% |
| 加速弹珠 | 移动速度+15% |
| 弹力球 | 弹性增强，碰撞后反弹更快更远 |

**稀有（蓝色）— 特殊效果，风险可控：**

| Buff | 效果 |
|------|------|
| 嗜血 | 击杀敌人恢复少量HP，但每次碰撞自损5% HP |
| 重型弹珠 | 质量增大，碰撞弹开敌人更远，但移速降低 |
| 溅射 | 碰撞命中时对周围敌人造成范围伤害 |
| 荆棘反伤 | 碰撞时对攻击者反弹部分伤害 |

**传说（金色）— 强力但带明显风险：**

| Buff | 效果 |
|------|------|
| 狂暴 | 攻击力+100%，但自身受到伤害+50% |
| 激昂 | 队伍中每阵亡一人，剩余士兵攻击力+10% |
| 先辈祝福 | 战斗开始时所有士兵临时+20% HP |

**特殊 Buff（叙事/主题类）：**

| Buff | 效果 |
|------|------|
| 虚空抗性 | 免疫一次虚空 Debuff |
| 幸运符 | 后续事件中出现更好选项的概率提升 |
| 磁铁 | 对附近敌人产生微弱吸引力，增加碰撞频率 |

#### 卡牌事件的风险决策

两个选项通常是"安全小奖励（绿色Buff）"vs"冒险大奖励（蓝色/金色Buff可能伴随Debuff）"，核心风险决策支撑 Roguelike 支柱。

#### 永久升级

- **性格 Buff：** Lv3 获得，不可更改，跟随士兵永久存在（详见兵种体系）
- **英灵殿：** Lv9 满级士兵送入，提供全队被动加成（永久）
- **无复杂装备系统：** 升级自动改变武器形态，无需手动管理

### 角色选择（Character Selection）

- **种族 = 将军：** 3种族（人类王国、精灵密林、兽人部落），选择种族即锁定将军技能风格
- **解锁机制：** 3种族初始全部解锁，无需逐步解锁
- **技能差异：** 每种族有独立技能组，影响将军在战斗中可释放的3次战略技能
- **编队自由：** 选择种族后可招募所有种族的士兵组成混合军队

### 难度修正（Difficulty Modifiers）

- **4档远征距离 = 4档难度：** 近郊巡逻（入门）→ 野外探索（普通）→ 深入腹地（困难）→ 传说远征（极难）
- **无额外诅咒/挑战模组：** 轻量 Roguelike，不增加复杂度
- **内在难度曲线：** 战斗序号递增的战力预算系统自然形成单次远征内的难度递增

## 进度与平衡

### 玩家进度

#### 进度类型

**局内进度（单次远征内）：**
- 士兵获取经验升级（Lv1→Lv9）
- Lv3 命名 + 性格 Buff（永久跟随士兵）
- Lv3/Lv6/Lv9 武器形态变化
- 卡牌事件获得临时 Buff

**局间永久进度（跨远征）：**
- 基地建设：解锁新兵种、升级设施
- 英灵殿：满级士兵送入提供全队被动加成
- 英魂重临：覆没远征产生的英魂在重玩时加入

**内容解锁进度（游戏进程）：**
- 失败解锁新卡牌事件
- 失败解锁新远征情报
- 事件池逐步丰富

#### 进度节奏

- 局内：每场战斗后立即感受到士兵成长，节奏快
- 局间：每次远征结束回到基地建设/解锁，中期驱动力
- 长期：事件池和远征路线的丰富需要多次游玩

### 难度曲线

#### 双层难度模型

**层1 — 远征内（锯齿形）：** 战斗序号递增的战力预算形成难度上升，每场战斗后通过升级/事件获得临时成长（"释放"），形成锯齿形曲线

**层2 — 远征间（玩家自选）：** 4档远征距离 = 4档难度，玩家自主选择。基地养成越强，能挑战的难度越高

#### 难度选择

无需传统难度调节，4档距离本身就是难度选择。新手自然从近郊开始，老玩家挑战传说。

### 经济与资源

#### 双资源系统

**蚀晶（Corruption Crystal）— 主要资源：**

虚空腐化在生物体内凝结成的晶体物质。各国研究院大量收购用于研究虚空本质，因此在民间流通成为一般等价物，可用于从商人处购买物品。

| 来源 | 说明 |
|------|------|
| 击杀敌人 | 每击杀一个敌人获得蚀晶，精英/Boss产出更多 |
| 撤退 | 已获得蚀晶全部保留（撤退直接结束远征） |
| 全军覆没 | 所有蚀晶归零 |

| 用途 | 说明 |
|------|------|
| 解锁新兵种 | 基地中解锁更高阶兵种的招募权 |
| 升级基地设施 | 提升兵营容量、训练场效率等 |
| 商人交易 | 购买远征物资、临时道具等 |

**英魂碎片（Soul Shards）— 叙事资源：**

| 来源 | 说明 |
|------|------|
| 命名士兵阵亡 | 每阵亡一名命名士兵获得碎片（Lv越高碎片越多） |
| 英魂重临完成 | 临时英魂完成远征后额外获得碎片 |

| 用途 | 说明 |
|------|------|
| 英灵殿升级 | 提升英灵殿的全队被动加成强度 |
| 纪念碑装饰 | 纯收集/叙事向，不影响数值 |

**双资源的情感张力：** 命名士兵的阵亡同时损失战力并获得英魂碎片——死亡既是损失也是馈赠，完美支撑"死亡转化为叙事而非惩罚"的设计理念。

## 关卡设计框架

### 结构类型

**线性序列 + 玩家自选** 的混合结构：

- **远征路线 = 一条线性事件链：** 出发 → 4~5个事件 → 战斗 → 4~5个事件 → 战斗 → ... → 最终战斗
- **玩家自选远征距离：** 4档距离对应不同的路线长度和难度
- **战斗场景：** 每场战斗在一个独立的弹珠竞技场中发生

### 远征路线

| 距离档位 | 预估时长 | 路线数量 | 战斗场次 |
|---------|---------|---------|---------|
| 近郊巡逻 | ~10min | 3条 | 2~3场 |
| 野外探索 | ~20min | 3条 | 4~5场 |
| 深入腹地 | ~30min | 3条 | 6~7场 |
| 传说远征 | ~40min | 3条 | 8~10场 |

- **解锁方式：** 4档距离初始全部可选，玩家根据实力自主选择
- **可重玩性：** 每条路线可反复游玩，卡牌事件随机保证每次不同
- **英魂重临：** 同一路线覆没后重玩有概率触发英魂事件
- **路线内容：** 不同路线在敌人组合、事件池权重、最终 Boss 上有所差异

### 战斗场景类型

| 场景类型 | 特点 | 视觉风格 |
|---------|------|---------|
| 森林（Forest） | 障碍物多，弹珠碰撞路径复杂 | 树木、岩石、树丛 |
| 道路（Road） | 开阔平坦，弹珠运动空间大 | 土路、石桥、路标 |
| 村镇（Town） | 建筑物作为掩体和障碍 | 房屋、围栏、广场 |
| 城堡（Castle） | 复杂地形，适合 Boss 战 | 城墙、塔楼、王座厅 |

**地形决定机制：** 战斗场景由卡牌事件中的玩家选择决定。例如遇到岔路口事件："左边是森林，右边是大路"，玩家的选择直接决定下一场战斗的地形。地形选择本身是一个策略决策——不同地形对不同兵种有不同影响，选择地形等于选择战术。

### 关卡设计原则

- **每一场战斗都是一场"弹珠秀"** — 地形设计优先考虑碰撞的视觉效果
- **30秒内有精彩碰撞** — 开局士兵快速接触，不拖沓
- **地形创造故事** — 障碍物让碰撞轨迹不可预测，产生"意料之外"的精彩瞬间
- **地形是策略资源** — 不同地形对不同兵种有不同影响，选择地形等于选择战术
- **新手引导融入事件链** — 第一条近郊巡逻路线的事件链兼顾教学功能

## 美术与音效方向

### 美术风格

**2D 卡通风格 + 豆豆眼弹珠角色**

#### 角色设计

弹珠是核心视觉载体，三层辨识系统：

| 层级 | 元素 | 说明 |
|------|------|------|
| 种族 | 球体颜色 + 豆豆眼风格 | 人类（暖色/圆眼）、精灵（冷色/细长眼）、兽人（大地色/三角眼） |
| 兵种 | 挂载装备 | 武器、盾牌、帽子区分13个兵种 |
| 命名 | 光环/名字标签 | Lv3+命名士兵头顶显示名字，有微弱光晕 |

#### 角色动画

- **碰撞挤压拉伸：** 球体在碰撞瞬间变形，物理弹性反馈
- **豆豆眼表情：** 碰撞时睁大眼、被击飞时惊恐脸、待机时偶尔眨眼
- **升级特效：** 升级时球体闪光 + 装备变换动画
- **士兵阵亡：** 豆豆眼闭眼，球体和装备变为深色，遗体永久留在战场原位（不消失）
- **命名士兵英雄陨落：** 在普通阵亡基础上，额外触发慢动作 + 英雄陨落专属音效 + 短暂"英雄安息"旋律

#### 色彩方案（明暗分区）

| 区域 | 色彩风格 | 说明 |
|------|---------|------|
| 基地 | 明亮温暖 | 安全感，成长的满足感 |
| 正常场景（森林/道路/村镇） | 自然明亮 | 弹珠碰撞在明亮背景下更醒目 |
| 城堡场景 | 偏暗偏冷 | 接近虚空前线的紧张感 |
| 虚空区域 | 暗紫/暗蓝 | 虚空侵蚀的压抑感，敌人弹珠为暗色调 |
| 同一远征内 | 逐渐变暗 | 越深入远征，场景色彩越偏冷，营造紧迫感 |

#### 视觉参考

- 弹珠角色：《世界 goo》的 goo 球、《毛线小精灵》
- 战斗场景：《奥日》的环境氛围
- 色彩分区：《空洞骑士》（正常区域温暖，深渊区域冰冷）的明暗对比

### 音效与音乐

#### 音乐风格

**动态管弦乐** — 以管弦乐为基础，融入电子元素表现虚空主题。

| 场景 | 音乐风格 | 说明 |
|------|---------|------|
| 基地 | 轻快民谣风 | 管弦 + 长笛/竖琴，安全感和归属感 |
| 森林战斗 | 活泼弦乐 | 轻快节奏，配合弹珠碰撞的趣味性 |
| 道路战斗 | 进行曲风 | 行军感，中速鼓点驱动 |
| 村镇战斗 | 热闹民乐 | 欢快，暗示人类聚居地的温暖 |
| 城堡战斗 | 史诗管弦 | 宏大的铜管+弦乐，Boss战氛围 |
| 虚空区域 | 电子+管弦混合 | 失真效果，不和谐音程，压迫感 |
| 英雄陨落 | 音乐骤停 → 单音符钢琴 | 所有乐器消失，仅剩一个缓慢下沉的钢琴音符 |

**动态音乐：** 战斗激烈时（大量碰撞同时发生）音乐节奏加快、配器加厚；战斗缓和时回归基础旋律。

#### 音效设计

**弹珠碰撞（核心音效）：**
- 基础音色：清脆弹珠碰撞声（台球质感）+ 低频冲击波
- 随碰撞力度变化：轻碰 = 高音清脆，重撞 = 低音沉闷 + 屏幕震动
- 随兵种变化：重装单位更沉厚，弓箭手更轻脆
- 连锁碰撞：快速连续碰撞形成"弹珠交响"，音量递增
- 击杀音效：碰撞音上叠加碎裂声 + 短促上升音

**将军事技能：**
- 释放前奏：种族特色音效（人类号角、精灵铃声、兽人战鼓）
- 释放瞬间：强力撞击/光效音

**系统音效：**
- 卡牌翻开：清脆翻牌声
- 升级：上升的闪亮音阶
- 获得Buff：魔法凝聚声
- 撤退信号：号角 + 淡出

**英雄陨落（命名士兵阵亡）：**
1. 战斗音效骤降（音量压低）
2. 背景音乐消失，仅留环境底噪
3. 一个缓慢的钢琴单音下沉
4. 弹珠变色的沉闷音效
5. 短暂的"英雄安息"旋律（2~3秒）
6. 恢复正常战斗音效

#### 语音

- **无全程语音和战斗语音：** 轻量实现
- **事件旁白：** 卡牌事件文字描述用打字机效果展示，无需语音

### 美学目标

美术和音效服务于四大支柱：
- **观赏性：** 豆豆眼 + 挤压拉伸 + 弹珠交响音效，让每场战斗都是视觉/听觉享受
- **叙事：** 命名士兵遗体留在战场 + 英雄陨落音效，将死亡转化为战场叙事
- **参与感：** 将军技能的种族特色音效让每次释放都有反馈感
- **Roguelike：** 明暗分区随远征深入逐渐变暗，营造紧迫感

## Technical Specifications

### Performance Requirements

| 指标 | 目标 | 说明 |
|------|------|------|
| 帧率 | 稳定 60fps+ | 战斗中大量弹珠物理碰撞时不得低于 45fps |
| 同屏弹珠数量 | 上限 100 个 | 单场战斗双方合计弹珠上限，超出时延迟生成 |
| 物理模拟步长 | FixedDelta 0.02s | Unity FixedUpdate 标准步长，保证碰撞检测稳定 |
| 内存占用 | PC ≤ 1GB | 移动端/小游戏 ≤ 512MB（待平台适配时验证） |
| 加载时间 | 场景切换 ≤ 3s | 战斗场景、基地场景的加载时间 |
| 包体大小 | PC 无限制 | 移动端/小游戏待调研（预估 ≤ 200MB） |

**性能优化策略：**
- 对象池复用弹珠、伤害飘字、HP 条等频繁创建销毁的对象
- 物理碰撞使用 Physics2D，远距离弹珠降低检测频率
- 战斗场景中的障碍物使用静态碰撞体
- 粒子特效使用 LOD，远处弹珠简化特效表现
- 弹珠预制体使用 SpriteRenderer + Rigidbody2D + CircleCollider2D 的轻量组合

### Platform-Specific Details

| 平台 | 渲染管线 | 输入方式 | 特殊适配 |
|------|---------|---------|---------|
| **PC (Steam)** | URP 2D | 鼠标键盘 | Steam 成就、云存档、创意工坊 |
| **移动端 (后续)** | URP 2D | 触摸 | 触控技能栏、双指缩放观战 |
| **微信/抖音小游戏 (后续)** | 团结引擎 | 触摸 | 包体压缩、小游戏 API 适配 |

**PC 首发优先：** 所有核心功能基于 PC 设计，移动端/小游戏在 PC 版完成后切分支适配。确保 PC 版玩法体验完整再进行平台迁移。

**输入适配重点：** 游戏核心为"观战为主 + 轻量干预"，每场仅 3 次技能操作，触摸操作天然友好。主要适配点为将军技能的底部技能栏点选 → 战场点击释放。

## Success Metrics

### Technical Metrics

| 指标 | 目标 | 衡量方式 |
|------|------|---------|
| 帧率稳定性 | 95% 帧时间 ≤ 16.67ms | Unity Profiler 统计 |
| GC 峰值 | ≤ 2ms/帧 | 对象池覆盖率 > 90%，运行时 GC 分配极小化 |
| 场景加载时间 | ≤ 3s | Addressable/AssetBundle 加载耗时 |
| 内存峰值 | PC ≤ 1GB | Profiler 内存面板 |
| 弹珠物理稳定性 | 无穿模/弹飞异常 | 100+ 弹珠同屏压力测试 |
| 崩溃率 | 0 | 单机游戏无联网崩溃风险 |

### Gameplay Metrics

| 指标 | 目标 | 说明 |
|------|------|------|
| 首场战斗爽感到达 | ≤ 60 秒 | 从点击开始到第一场弹珠碰撞混战 |
| 单次远征时长 | 10~40 分钟 | 4 档距离对应不同时长 |
| 命名士兵阵亡情感冲击 | 玩家主动截图/分享 | 通过慢动作 + 音效 + 叙事触发情感共鸣 |

## Out of Scope

以下内容**不在**本游戏首发范围内，可能作为后续更新考虑：

### 明确排除

| 排除项 | 原因 |
|--------|------|
| **多人对战 / 联机** | 纯单机体验，网络功能复杂度过高，不符合个人开发资源限制 |
| **装备/物品栏系统** | 升级自动改变武器形态，无需手动管理装备，保持轻量化 |
| **深度的经济/交易系统** | 蚀晶资源系统保持简单（获取→消费），无交易/市场机制 |
| **副本/地下城等复杂关卡结构** | 远征 = 线性事件链，不做分支关卡或开放地图 |
| **宠物/坐骑/伴侣系统** | 超出核心玩法范围 |
| **剧情过场动画 / 对话系统** | 叙事通过出征描述文本 + 涌现式叙事实现，不做 CG/对话 |
| **成就/奖杯系统（首发）** | Steam 成就可在后续更新添加 |
| **创意工坊（首发）** | 玩家自制内容在核心玩法验证后再考虑 |
| **PVP 排行榜** | 无对战需求 |
| **赛季/通行证** | 非免费游戏，无实时运营需求 |
| **本地化（首发）** | 首发仅支持中文，后续按需翻译 |
| **关卡编辑器** | 已有 WorldEditor 工具仅供内部使用，不面向玩家 |

### 设计边界

- **Roguelike 是手段而非卖点：** 不追求《Hades》级别的深度 Roguelike，事件链保持轻量
- **观赏性 > 策略深度：** 宁可简化策略系统也要保证战斗好看
- **个人开发约束：** 所有系统设计必须考虑单人实现的可行性

### 关键路径风险

**MVP 关键路径：** E0（战斗原型）→ E1（兵种升级）→ E3（将军技能）→ E6（卡牌事件）→ E7（远征流程）→ E11（UI 串联）

关键路径上任何 Epic 延期都会直接影响 MVP 交付。最大风险在于 **E0 弹珠物理性能**——如果 100+ 弹珠无法稳定 60fps，需要降低同屏数量上限或优化物理模拟，可能影响观赏性。

### 外部因素

- **短视频平台算法变化：** 弹珠战斗内容的自然传播依赖平台推荐，算法调整可能影响获客
- **竞品出现：** 目前无直接竞品，但弹珠战斗视频的高播放量可能吸引其他开发者
- **Unity 版本/政策变化：** 个人版许可政策或引擎功能调整（如 Runtime Fee 事件）需关注
