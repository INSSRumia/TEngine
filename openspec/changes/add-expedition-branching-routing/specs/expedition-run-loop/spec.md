## MODIFIED Requirements

### Requirement: 玩家可以从最小入口发起一次远征
系统 SHALL 提供一个最小入口界面，用于发起一次远征；该入口界面在本次变更中不承担完整家园玩法，只负责进入远征流程。系统在启动远征时 MUST 基于 Luban 生成的远征主配置创建本次远征所需的静态节点图上下文和初始待执行节点队列，而不是继续依赖硬编码静态工厂数据或固定索引路线。

#### Scenario: 从入口开始远征
- **WHEN** 玩家在入口界面点击开始远征
- **THEN** 系统创建一份新的 `ExpeditionRunState`
- **AND** 系统将本次入口选择的 Marble 持久化数据复制为远征内快照
- **AND** 系统根据 Luban 远征主配置装载本次远征的节点图与初始待执行节点队列
- **AND** 远征流程进入准备完成后的首个节点推进阶段

### Requirement: 远征 SHALL 按节点图与运行时队列推进
系统 SHALL 将一次远征表示为静态节点图与运行时待执行节点队列的组合，并按当前节点的路由策略决定后续流程。系统不再要求远征只能按单一线性节点顺序推进。

#### Scenario: 节点根据路由策略决定后续流程
- **WHEN** 当前节点完成结算
- **THEN** 系统根据当前节点的固定出口、选项出口或条件出口策略更新待执行节点队列
- **AND** 下一个节点从待执行节点队列中取得

#### Scenario: 运行中插入新的事件节点
- **WHEN** 当前远征在运行过程中满足某个动态插入条件
- **THEN** 系统向待执行节点队列插入新的事件或支线节点
- **AND** 不要求预先把该节点固定放在线性主路中
