## MODIFIED Requirements

### Requirement: 远征主表 SHALL 使用节点图与节点级路由配置表达流程
系统 MUST 使用远征主表中的节点图与节点级路由配置表达远征流程；节点至少需要支持固定出口、按选项出口和按条件出口三种模式。Event 模板本身不承载出口语义。

#### Scenario: 节点按配置声明路由策略
- **WHEN** 某条远征被配置为可分支远征
- **THEN** 其节点配置显式声明自身的路由策略
- **AND** 其节点出口由节点级配置表达
- **AND** 不要求通过 Event 模板复制来表达不同节点的出口逻辑

### Requirement: 事件配置 SHALL 保持内容模板职责
系统 MUST 让远征事件配置继续只定义事件标题、描述和选项内容；选项本身不直接携带当前节点实例的出口语义。

#### Scenario: 同一 Event 被多个节点复用
- **WHEN** 运行时读取某个被多个节点复用的 Event 配置
- **THEN** 该 Event 仅提供内容与选项定义
- **AND** 不要求在 Event 配置中直接写死不同节点实例的出口目标
