## 2. 随机事件池运行态

- [x] 2.1 设计并实现随机事件池运行态数据结构，能够按池保存剩余可抽条目，而不是按全局 Event 历史去重。
- [x] 2.2 实现激活随机事件池集合，并记录池来源，至少区分远征基础池和当前环境池。
- [x] 2.3 实现随机事件池初始化逻辑：远征开始时激活远征基础池与初始环境池。
- [x] 2.4 实现加权抽取算法：先按所有有效激活池总权重定位池，再将随机值转换为池内局部权重抽取事件。
- [x] 2.5 抽中事件后只从命中的池移除对应条目；不同池中相同 Event 仍可分别被抽中。
- [x] 2.6 处理空池和无效权重：空池、总权重小于等于 0 的池不参与抽取，所有池都不可用时返回无事件结果。

## 3. RandomEvent 节点流程

- [x] 3.6 为随机事件节点关键路径添加调试日志，尤其是空池跳过和无效权重跳过。
